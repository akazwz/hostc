hostc
For agents

Localhost,
anywhere.

One command gives your dev server a public HTTPS URL. WebSockets and hot reload work through it, so every save shows up for whoever has the link. Free, with no account.

$npx hostc@latest 3000

Needs Node.js 22 or later. Run it with --help to see every option.

What you get

Hot reload works
WebSockets pass straight through, so Vite and Next.js hot reload update the page on every device the moment you save.
Dev servers just work
Requests arrive addressed to localhost, so dev servers accept them without configuration.
Everything else gets through
Pages, APIs and forms, Server-Sent Events and streaming, and uploads of any size.
The URL stays put
After a network drop or a server restart, hostc reconnects to the same tunnel. The link you shared keeps working.
Nothing to set up
No account, no config file, nothing to install. Press Ctrl+C and the URL is gone.

vs Cloudflare Tunnel

hostc runs on Cloudflare too. It does one narrower job than Cloudflare's own tunnels: sharing a dev server for a while.

Good to know

The URL is public
Anyone who has it reaches your server. Share only what you mean to, never anything holding secrets.
Always @latest
hostc is free and moves fast. An outdated CLI exits at startup and tells you to upgrade.
Coding agents
They run the same command and read the URL from its output. llms.txt tells them how.
Your own domain
The server is an open-source Cloudflare Worker. Deploy it to your account.
