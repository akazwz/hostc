---
title: 怎么把 localhost 分享给别人看
description: 让别人打开你电脑上网站的四种方法，从局域网地址到内网穿透，以及该怎么选。
date: 2026-11-06
---

网站在 `localhost:3000` 上跑得好好的，你想让同事、客户或者自己的手机看看。但 `localhost` 永远指“这台机器”，把这个链接发给别人，他们什么也看不到。实际可选的办法有四个。

## 1. 局域网 IP

如果对方和你在同一个网络，可以用电脑的地址，比如 `http://192.168.1.20:3000`。

- **适合：** 手边的手机。
- **问题：** 两台设备必须在同一网络；很多开发服务默认只监听 localhost，要额外设置（`vite --host`、`next dev -H 0.0.0.0`）；而且不是 HTTPS，所以[摄像头这类功能用不了](/zh/blog/https-on-localhost)。

## 2. 内网穿透（隧道）

一个小程序向公网服务器发起连接，服务器给你一个地址。[原理在这里](/zh/blog/what-is-a-localhost-tunnel)。

```sh
npx hostc@latest 3000
```

- **适合：** 几秒钟内分享给任何地方的任何人；接收 Webhook。
- **问题：** 电脑开着、隧道运行时链接才有效；拿到链接的人都能访问你的服务。

## 3. 路由器端口转发

让路由器把外部流量转到你的电脑。

- **适合：** 现在几乎没有适合的场景。
- **问题：** 很多家庭宽带没有公网 IP（运营商级 NAT），可能根本不通；它会把电脑直接暴露出去，而且你还得自己解决 HTTPS。

## 4. 部署预览

推到 Vercel、Netlify 或 Cloudflare 这样的平台，分享预览地址。

- **适合：** 别人明天或下周还要看的东西。
- **问题：** 需要配置，每次改动都要重新构建；本地数据库和服务都不在那边。

## 怎么选

| 你想做的           | 用什么          |
| ------------------ | --------------- |
| 在自己手机上看网站 | 隧道或局域网 IP |
| 给同事看五分钟     | 隧道            |
| 接收 Webhook       | 隧道            |
| 给客户看几天       | 部署            |
| 正式运行           | 部署            |

分享之前先想想你的服务暴露了什么。隧道会让它变成公开的，所以不要带上管理后台、数据库和密钥，用完就停掉。
