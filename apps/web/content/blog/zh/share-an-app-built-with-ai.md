你让 AI 写了个应用，它跑起来了，屏幕上写着 `Local: http://localhost:3000`。你想让朋友试试，但这个链接只有你的电脑能打开。

部署当然可以，但对刚做出来的东西有点麻烦：你可能没有托管平台的账号，应用可能还依赖本地数据库。

## 用隧道分享

让应用继续跑，再开一个终端，用它打印的端口：

```sh
npx hostc@latest 3000
```

你会得到一个公网 HTTPS 链接。发给任何人，他们都能在任何设备上使用你电脑上跑着的应用。AI 继续改代码时，对方的页面也会跟着更新。

## 让编程助手来做

编程助手可以自己运行这条命令。这样告诉它：

```text
阅读 https://hostc.dev/llms.txt，然后用公网链接分享这个应用。
```

这个文件告诉它怎么启动 hostc、怎么读取地址。

## 分享前检查这几项

AI 写的应用可能没处理这些问题，分享前看一下：

- 写在前端代码里的 API Key，打开页面的人都能看到。要放在服务端。
- 如果管理后台不用登录，链接就把它暴露了。
- 如果应用调用付费接口，访客用的都是你的额度。最好只发给认识的人，并设置消费上限。
- 用测试数据，不要用你自己的文件或客户资料。

## 什么时候该部署

电脑开着、hostc 运行时，这个链接才有效。如果别人明天还要用，或者你不在时也要用，就该部署了。
